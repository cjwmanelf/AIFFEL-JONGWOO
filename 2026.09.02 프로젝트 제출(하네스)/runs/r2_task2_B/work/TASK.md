# task2 — refactor-util

`util.py` 의 함수 3개(`slugify`, `chunk`, `retry_delays`)에 **타입 힌트와 독스트링**을 추가한다.

## 요구 사항

1. 세 함수 모두 **모든 매개변수에 타입 주석**을 달고 **반환 타입 주석**을 단다.
2. 세 함수 모두 **독스트링**을 단다. 첫 줄은 한 줄 요약으로 쓴다.
3. **동작은 바꾸지 않는다.** 함수 이름, 매개변수 이름, 기본값, 반환값이 그대로여야 한다.
4. 표준 라이브러리만 쓴다. `typing` 사용은 자유.

## 완료 판정

```
python verify.py
```

가 `PASS` 를 출력하면 완료. `verify.py` 는 채점기이며 읽어 봐도 된다. **수정하면 안 된다.**
