# task1 — parse-log

`sample.log` 에서 **오류 줄만** 골라 코드별 건수를 표로 정리하는 스크립트 `parse.py` 를 작성한다.

## 요구 사항

1. 같은 폴더의 `sample.log` 를 읽는다. (경로 하드코딩 허용)
2. **레벨이 `ERROR` 인 줄만** 집계한다.
   `INFO`/`WARN`/`DEBUG` 줄의 본문에 `ERROR` 나 `code=` 가 들어 있어도 세면 안 된다.
3. 각 줄의 `code=Exxx` 값을 뽑아 건수를 센다.
4. 표를 **표준 출력(stdout)** 으로 찍는다. 형식은 CSV 로 고정한다.
   - 첫 줄: `code,count`
   - 이후: `E401,4` 처럼 `코드,건수`
   - 정렬: 건수 내림차순, 건수가 같으면 코드 오름차순
5. 표준 라이브러리만 쓴다. (이 환경에는 pytest 등 외부 패키지가 없다)

## 완료 판정

```
python verify.py
```

가 `PASS` 를 출력하면 완료. `verify.py` 는 채점기이며 읽어 봐도 된다. **수정하면 안 된다.**
