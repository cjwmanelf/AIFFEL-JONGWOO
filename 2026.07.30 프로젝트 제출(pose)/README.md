# 원하는 포즈로 이미지 만드는 도구

## 도구 설명
- 이 도구는 FLUX.2-klein-4B 모델을 이용한 일반 이미지 생성과, ControlNet OpenPose 기능을 활용한 SD1.5 기반 이미지 생성을 제공하는 Gradio UI입니다.

## 사용법
1. Colab 상단 메뉴에서 파일 > 노트 열기 (Ctrl + O 또는 Cmd + O) 선택

2. [13]번셀 GPU 사용 가능 확인 셀 : PyTorch 및 CUDA 환경이 정상 구동되는지 확인합니다.
   
[5]번셀 ComfyUI 본체 및 GGUF 노드 설치 셀 : ComfyUI 및 필요 라이브러리를 다운로드하고 환경을 세팅합니다.  

[7]번셀 모델 파일(FLUX.2-klein) 다운로드 셀 : 생성에 필요한 디퓨전 모델, 텍스트 인코더, VAE를 지정된 폴더에 받습니다.  

[11]번셀 SD1.5 & ControlNet OpenPose 모델 다운로드 셀 : 포즈 제어용 저용량 모델 및 관련 전처리 노드를 설치합니다.  

[15]번셀 ComfyUI 백그라운드 서버 실행 셀 : 백엔드로 작동할 ComfyUI 서버(8188 포트)를 켭니다.  

[16]번셀 Gradio UI 실행 셀 : 사용자가 프롬프트와 포즈 사진을 입력해 이미지를 생성할 수 있는 웹 UI 링크를 출력합니다.  

3. Google Colab 세션 저장소 (파일 탐색기), /content/ComfyUI/output/ 폴더
